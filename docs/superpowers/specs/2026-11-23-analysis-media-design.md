# 실보드 분석 자료와 GUI 동영상

사용자 요청: GUI 동영상과 시험 결과의 표/그래프. 선택한 용도는 문서용 짧은 무음 시연이다.

자료는 기존 시험 기록에서 생성한다. 제품 GUI에 재생 기능을 추가하지 않고 자료 제작 도구가
실제 기록을 기존 위젯에 전달한다. 영상 전체에 recorded replay 표시를 유지한다.
약40초 MP4는 소개, 약15초 기록의1배속 재생, TRACK/STATUS 정지 화면, 요약으로 구성한다.
영상의139개 측정 세션은 최신30분 성능 실행과 서로 다른 기록임을 명시한다.

접근 비교: 새 실보드 녹화는 새로운 입출력/호스트 영향을 만들고, 가상 데이터는 실측 증거가
되지 않는다. 기존 실보드 세션 재현은 데이터 출처를 보존하며 재현할 수 있어 선택했다.
사용자는 무음 시연 용도를 선택했고, 저장 기록 재현과 분석 구성은 assistant의 제작 선택이다.

분석은 최신30분 보드 지연 분포/자원, 호스트 RTT/송신 공백/슬롯 누락, 별도 선회 궤적과
오차를 다룬다. 서로 다른 시계를 직접 빼거나 누적 최댓값을 순간 값으로 표시하지 않는다.
선회 오차는 최초2초를 제외한 기존 지표와 대조하고 새 합격 한계를 만들지 않는다.

산출물은 `docs/analysis/2026-11-23/`에 HTML, Markdown, PNG/SVG, CSV/JSON과 MP4로 저장한다.
원시 증거와 제품/판정 코드는 유지하고 릴리스 상태는 변경하지 않는다.
